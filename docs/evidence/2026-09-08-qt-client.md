# class-mid Qt 客户端验证记录

日期：2026-09-08

## 修改范围

- 新增 `qt/`：Qt 6 Widgets 客户端，直连 `127.0.0.1:8080` 的 JSON HTTP 与 WebSocket。
- 覆盖注册/登录、AUTH、快照、购买、种植、施肥、收获、清理、出售、领奖、邮箱与未确认写请求恢复。
- 客户端不连接 MySQL，不持久化 token 或密码。

## 实际验证

构建目录必须使用纯英文路径。`moc` 在 `D:\课设\...` 下无法创建生成文件。本次构建：

```text
cmake -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.11.2/mingw_64 -DCMAKE_BUILD_TYPE=Release
```

源码：`qt/`；构建目录：用户临时目录下的 `classic-farm-qt-build`。

- `classic_farm.exe` 与 `classic_farm_smoke.exe` 链接成功。
- `GET /healthz` 本机 8080 可用（当时后端为内存模式）。
- `classic_farm_smoke.exe` 输出 `qt smoke ok`：注册新账号、AUTH、初始快照为 10 金币 / 0 种子 / 1 肥料 / 4 块地，购买 3 颗种子后为 4 金币 / 3 种子，并能读到欢迎邮件。

未打印 token、密码或 DSN。未做 Qt GUI 自动化点击，也未声称公网部署或 Qt 单元测试套件通过。
