# H5 图鉴新解锁红点

## 行为

- 玩家快照或状态 Patch 出现新的 `unlocked_crop_ids` 时，顶部图鉴按钮显示红点。
- 第一次打开图鉴时，尚未读的新解锁作物条目分别显示红点。
- 打开不会立即清除；关闭图鉴或从图鉴切换到其他抽屉时，才把当前解锁列表
  记录为该玩家在此浏览器上的已读基线，并原子清除本次提示。
- 已读列表按 `player_id` 存在浏览器 `localStorage`。首次启用功能时以当前列表
  为基线，不把历史解锁全部误报为新增；重新登录也能识别离线期间新增的解锁。
- `localStorage` 不可用时游戏仍可继续运行，但已读状态不能跨刷新保存。

权威图鉴内容仍来自 Zone 返回的玩家快照/状态 Patch。本改动没有新增服务端
协议、数据表或持久化字段。

## 验证

在 `web/` 执行：

```bash
npm run typecheck

npm run build
```

结果：5 个测试文件、28 项测试通过，Vite 生产构建成功。新增回归覆盖按钮红点、
具体条目红点、关闭确认以及已读列表持久化。
