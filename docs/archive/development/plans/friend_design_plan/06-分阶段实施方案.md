# 好友功能分阶段实施方案

## 总原则

- 每阶段必须保持现有单玩家业务和纯 Tcaplus 双 Zone E2E 通过；
- 先完成传输和持久化基础，再增加好友业务；
- 普通单玩家命令继续异步 Dirty，只有跨玩家 Saga 使用同步 SaveCAS；
- 每阶段独立提交、独立证据，未通过验收不得进入下一阶段；
- 不同时维护含义相同的 HTTP 和 gRPC 长期双入口。
