# 历史资料归档

本目录保存设计演进和个人工具配置，不属于当前交付方案。归档材料用于回答
“项目如何演进”一类追溯问题，不能覆盖当前架构、合同、ADR 或实测证据。

## 内容

- `architecture-v1-v2/`：已被 V3 取代的无状态 V1 和同步 Journal V2 架构。
- `architecture-history/`：整理前重复或过时的架构、实现总览与文档体系说明。
- `handoff-history/`：压缩前的完整开发交接日志。
- `development/plans/`：开发期间的开放问题、执行计划和阶段任务。
- `development/ai-workflow/`：按日期记录的 AI 辅助开发过程。
- `development/study/`：个人学习、复盘和讲解笔记。
- `development/superpowers/`：工具生成的细粒度实施方案。
- `evidence/historical/`：功能开发期间的细粒度验收、旧存储/部署基线和中间实验。
- `tooling/`：个人文档工具配置，不属于项目设计或运行资料。

这些材料保留用于追溯，但已从最终交付阅读路线中排除。引用它们时必须明确其
历史或过程性质，不能将计划中的预期结果表述为已经实现或实测的结论。
