# class-mid 当前状态

更新时间：2026-09-08

## 已完成

- 从 `main` 创建本地分支 `class-mid`。
- 后端收敛为一个入口：`server/cmd/game`，默认监听 `127.0.0.1:8080`。
- 注册、登录、注销改为 HTTP JSON；游戏通信改为 WebSocket 文本 JSON。
- 删除独立 LoginSvr、GateSvr、Coordinator、Zone 路由、Shard、Actor、Protobuf 和旧内部 RPC。
- 保留单人农场闭环：买种子/肥料、种植、施肥、成熟、收获、出售、任务领奖、清理。
- MySQL 使用三张独立的 `class_mid_*` 表；成功操作同步事务提交后才响应。
- MySQL 新增 `class_mid_mails`；新玩家注册时账号、初始农场和欢迎邮件在同一事务提交。
- 邮箱通过 `GET_MAILBOX` 实时查询，通过 `READ_MAIL` 标记本人邮件已读；不含附件、删除、分页或推送。
- Vue 已切换到 JSON，并保留完整可操作界面；未确认写操作保存原 request_id，重新登录后可以继续确认。
- 新增 `qt/` Qt 6 Widgets 客户端，复用同一 JSON 合同；不连接 MySQL。
- 删除旧分布式部署、压测、测试平台、生成代码和历史文档；旧内容仍可从 `main` 分支恢复。

## 已验证

- Go 单元、HTTP、WebSocket、并发与事务测试通过。
- 使用本机 MySQL 完成新表写入、重新连接读取与重复请求去重验证。
- `go vet ./...` 通过。
- Vue 网络恢复测试、TypeScript 类型检查及生产构建通过。

详细命令和边界见 `../evidence/2026-09-07-class-mid.md` 与 `../evidence/2026-09-08-qt-client.md`。

## 当前限制

- Session 只在进程内保存；服务重启后重新登录。
- 内存模式重启丢失全部数据；MySQL 模式保留账号、存档与最近 100 个成功写请求。
- 第一版没有主动成熟推送；客户端通过 20 秒心跳及操作响应获取完整快照。
- 仅胡萝卜一种作物、4 块地和固定配置，没有好友与管理员系统；旧账号不补发欢迎邮件。
- 当前仅验证本地运行，不代表公网安全、生产高可用或大规模性能能力。
- C++/Qt 客户端已放在 `qt/`，接口契约见 `../contracts/json-api.md`。
- 已补充 `../qt-client-guide.md`，包含 Qt 6 网络代码、全部接口、错误处理和重构顺序。
- 已补充架构、代码 Review、测试清单和中期答辩讲解文档。
