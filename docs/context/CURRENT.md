# class-mid 当前状态

更新时间：2026-09-14

## 当前实现

- 后端入口只有 `server/cmd/game`，默认监听 `127.0.0.1:8080`。
- 注册登录与好友使用 HTTP JSON；农场操作和邮箱使用 WebSocket JSON。
- MySQL 有账号、玩家、作物、仓库、农田、任务定义、玩家任务、邮件、好友 9 张表。
- 新玩家有 50 金币、2 个肥料、16 块空地、6 条仓库记录和一封欢迎邮件。
- 商店有 6 种作物，成熟时间为 30–60 秒。
- 好友关系双向保存。好友可查看农田、偷取成熟作物和投递邮件。
- 偷菜后偷取者获得完整产量和 1 金币，对方地块变为 `NEED_CLEANUP`。
- 旧 Qt JSON 字段和已有路径仍可用；新好友界面尚未加入 Qt，可运行 `scripts/demo-friends.ps1` 演示。

## 已验证

- `go test ./... -count=1` 和 `go vet ./...` 通过。
- 本机 MySQL 已用重建脚本生成 9 张表和 6 种作物。
- 两个真实账号完成注册、登录、WebSocket 买种子和种植、加好友、查看 16 块地、等待成熟、偷菜和发邮件。

## 限制

- Session 只存在进程内，服务重启后需重新登录。
- 凯撒密码只适合课程演示。
- 为保持代码短小，没有请求去重、好友申请确认、偷菜次数限制、分页和成熟推送。
- 旧 `classic_farm_smoke` 把 4 块地和旧初始数值写死，因此其断言已过期；Qt 主界面按服务端数组动态显示。
