# 项目范围

- 分支：`class-mid`，单 Go 游戏服务器，JSON HTTP/WebSocket，MySQL InnoDB。
- 功能：注册登录、16 块农田、6 种作物、商店、仓库、种植、施肥、收获、出售、任务、邮箱、好友、查看好友农场、偷菜和好友邮件。
- 数据用 9 张 `class_mid_*` 关系表保存；写操作使用数据库事务，修改地块时使用 `SELECT ... FOR UPDATE` 行锁。
- Qt 和 Vue 都是客户端，只调用接口，不直接连接数据库。
- 不包含多 Zone、Gate、Coordinator、Shard、Actor、Protobuf 和分布式部署。
- 目标是本地课设演示与可讲解性，不主张公网安全或生产并发能力。
- 密码按课程要求用简单凯撒移位存储。它只能体现编码过程，不能代替真实项目中的密码哈希。
- AI 辅助记录如实保留，不作无 AI 开发声明。
