# Plans

Store bounded execution plans here. A plan should state:

- Goal.
- Scope and non-goals.
- Relevant context and decisions.
- Steps.
- Verification.
- Stop conditions and risks.

Plans describe intended work. `docs/context/CURRENT.md` describes the actual current state.
