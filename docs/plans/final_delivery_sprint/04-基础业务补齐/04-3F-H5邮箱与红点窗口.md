# H5 邮箱与红点窗口 Implementation Plan

> **For agentic workers:** H5 只展示服务端权威结果。不得在前端自行判断邮件可见性、附件合法性或好友农场是否真的可偷。

**Goal:** 增加可点击的小型邮箱窗口、邮箱红点、好友农场红点和好友赠礼入口。

## UI 范围

主界面：

```text
[邮箱 🔴]
```

好友列表：

```text
好友A  [进入农场 🔴] [赠送礼物]
好友B  [进入农场]    [赠送礼物]
```

邮箱窗口：

```text
邮箱

[全部] [公开] [私人] [好友礼物]

邮件标题
寄信人
收信人
时间
正文
附件
状态：未读 / 已读 / 已领取
[领取]
```

不需要邮件图片。

## 状态规则

- 收到 `MAIL RED_DOT SET`：邮箱按钮显示红点。
- 点击邮箱：立即清除本地红点并请求 MailSvr。
- 查询失败时显示失败提示，不伪造邮件列表。
- 收到 `FRIEND_FARM RED_DOT SET(ownerID)`：对应好友按钮显示红点。
- 点击对应“进入农场”：清除该好友本地红点。
- 红点不写浏览器长期存储；刷新或重连后由服务端新事件决定。
- 未领取旧邮件不会因重新登录自动显示新红点。

## Task 1：红点状态

- [ ] WS 客户端处理 `RED_DOT_CHANGED`。
- [ ] 邮箱红点使用布尔状态。
- [ ] 好友红点使用 `Set<ownerPlayerID>`。
- [ ] 重复 SET 幂等。
- [ ] 未知 category 安全忽略并记录。
- [ ] 点击对应按钮后本地 CLEAR。
- [ ] 红点变化不直接触发领取或偷菜。

## Task 2：邮箱窗口

- [ ] 点击邮箱后打开小窗口。
- [ ] 调用 `OpenMailbox`。
- [ ] 支持分页或“加载更多”。
- [ ] 按时间倒序展示。
- [ ] 显示：
  - 邮件类型；
  - 时间；
  - 寄信人；
  - 收信人；
  - 标题；
  - 正文；
  - 附件；
  - 已读/已领取状态。
- [ ] 打开邮件时调用 MarkRead。
- [ ] 有附件且未领取时显示领取按钮。
- [ ] 领取期间禁用重复点击。
- [ ] 仓库不足显示服务端错误，邮件保持未领取。
- [ ] 成功后更新邮件和仓库权威状态。

## Task 3：好友赠礼窗口

- [ ] 点击“赠送礼物”打开窗口。
- [ ] 只显示仓库中的作物。
- [ ] 每次选择一种作物。
- [ ] 数量限制 1–10 且不能超过库存。
- [ ] 显示固定邮件模板预览。
- [ ] 发送期间禁用重复点击。
- [ ] 成功后使用服务端响应更新仓库。
- [ ] 非好友、库存不足和重复请求显示确定错误。

## Task 4：好友成熟红点

- [ ] 按 `source_player_id` 设置对应好友红点。
- [ ] 点击该好友进入按钮时清除。
- [ ] ENTER 失败也不自动恢复旧红点。
- [ ] 进入农场后以 Owner Actor 返回状态判断是否可偷。
- [ ] 好友列表刷新时不根据本地作物状态猜测红点。

- [ ] 不出现横向溢出。
- [ ] 长标题和正文可换行。
