# 好友功能验收与测试清单

## 1. FriendSvr

- [ ] 好友代码创建后 10 分钟内可被多个不同玩家兑换；
- [ ] 代码过期后拒绝兑换，之后才允许创建新代码；
- [ ] 自己不能兑换自己的代码；
- [ ] 同一人重复兑换不重复占名额；
- [ ] 每人第 101 个好友被拒绝；
- [ ] FriendLinkSaga 在任一步中断后不会暴露可访问的单向好友；
- [ ] 好友列表返回最多 100 个 `account_name`。

## 2. 访问与心跳

- [ ] H5 一次只能访问一座好友农场，切换自动退出旧农场；
- [ ] 非双向好友不能 `ENTER_FARM`；
- [ ] 成功进入返回公开快照和 `visit_id`；
- [ ] 30 秒心跳刷新访客表；
- [ ] 90 秒无心跳清除访客；
- [ ] `EXIT_FARM` 立即清除访客；
- [ ] Owner Zone 重启后旧 `visit_id` 被拒绝，H5 自动重新进入；
- [ ] 农场主收到访客进入/离开的短暂提示。

## 3. 公开同步

- [ ] 公开视图不包含金币、背包、任务和行动次数；
- [ ] 农场主和多个访客收到相同公开地块变化；
- [ ] 私有买种等变化不增加 `farm_view_seq`；
- [ ] 公开地块变化才增加 `farm_view_seq`；
- [ ] `farm_view_epoch` 改变后 H5 用完整快照替换旧视图；
- [ ] Push 丢失或版本缺口时，重新进入后快照收敛。

## 4. 四种互动

- [ ] 访客投虫、捉虫、清理成功后各扣一次相应机会；
- [ ] 农场主自己捉虫、清理不扣机会；
- [ ] 同一块成长地不能同时存在两只虫；
- [ ] 虫源不能捉自己投下的虫；
- [ ] 两名访客并发操作同一地块时，先进入农场主 Actor Mailbox 的请求成功；
- [ ] 被偷次数、保护产量和单次偷取量均按冻结配置校验；
- [ ] 偷取不满足条件时不增加 `stolen_quantity`，也不向访客发作物；
- [ ] 第二章偷取任务只在访客 Saga 完成后推进。

## 5. Saga 恢复

- [ ] 相同 `interaction_id` 重试不会重复扣机会、加作物或改地块；
- [ ] `VISITOR_RESERVED` 阶段中断后可释放预留；
- [ ] `OWNER_APPLIED` 阶段中断后可从农场主回执继续访客提交；
- [ ] `VISITOR_COMMITTED` 阶段中断后重试返回相同完成结果；
- [ ] Tcaplus CAS 冲突、重试性失败、旧副本和 Fence 拒绝均不会误判完成；
- [ ] 未完成 Interaction 会被 Actor 激活或 Zone 定时任务对账；
- [ ] 终态 Interaction 保留 24 小时，未完成记录不自动删除。

## 6. 端到端演示

- [ ] 两名玩家建立好友；
- [ ] 访客进入农场主农场，农场主看到进入提示；
- [ ] 两个访客同时查看农场主农场；
- [ ] 一名访客完成投虫、捉虫、清理和偷取；
- [ ] 三个 H5 的公开地块视图一致；
- [ ] 访客离开或超时后，农场主不再向其下发公开 Patch；
- [ ] 完整停止并恢复服务后，好友关系和 Saga 终态保持正确。
