# 好友功能验收与测试清单

## 实施前评审结论

总体业务方向合理，与当前 Player Actor、双 Zone 路由和 Tcaplus 单记录
CAS 模型兼容。2026-08-05 已确认以下实施决策：

1. 完成游戏内部 gRPC 改造：迁移 Gate → Zone 命令和 Zone → Gate Push，
   新增 FriendSvr、Zone → Zone RPC；Login 与 Coordinator HTTP 本期不改。
2. `FriendRelation(min_player_id, max_player_id)` 是唯一权威关系；
   `FriendList` 是可修复查询投影，并持久化按 `link_id` 区分的 reservation。
3. `FriendCodeCurrent` 以 `owner_player_id` 为主键保证一人一个有效代码，
   `FriendCodeLookup` 提供按代码查找。
4. 访客 reservation/receipt 与 Owner applied receipt 进入各自 Player
   Checkpoint；`FriendInteraction` 只记录编排进度。
5. `farm_view_epoch` 在 Owner Actor 激活和 Shard 迁移后变化。
6. 内部 gRPC 最小原型使用 timestamp + nonce + body digest 的 HMAC
   Metadata，并按 caller service 授权。
7. 第二章包含三个任务：双方成功建立好友关系各推进一次、偷菜一次、
   向好友地块投虫一次。

下面的验收项是开发门禁。

## 1. FriendSvr

- [ ] 好友代码创建后 10 分钟内可被多个不同玩家兑换；
- [ ] 代码过期后拒绝兑换，之后才允许创建新代码；
- [ ] 自己不能兑换自己的代码；
- [ ] 同一人重复兑换不重复占名额；
- [ ] 每人第 101 个好友被拒绝；
- [ ] 并发兑换不会让任一方超过 100 人，失败/中断 reservation 可对账释放；
- [ ] FriendLinkSaga 在任一步中断后不会暴露可访问的单向好友；
- [ ] 伪造调用者身份或绕过 Saga 状态不能通过 `CheckMutualFriend`；
- [ ] 好友列表返回最多 100 个 `account_name`。
- [ ] `FriendRelation` 激活后双方“加好友”任务各推进一次，重试不重复推进。

## 2. 访问与心跳

- [ ] H5 一次只能访问一座好友农场，切换自动退出旧农场；
- [ ] 非双向好友不能 `ENTER_FARM`；
- [ ] 成功进入返回公开快照和 `visit_id`；
- [ ] 30 秒心跳刷新访客表；
- [ ] 90 秒无心跳清除访客；
- [ ] `EXIT_FARM` 立即清除访客；
- [ ] Owner Zone 重启后旧 `visit_id` 被拒绝，H5 自动重新进入；
- [ ] Owner Shard 迁移后旧 `visit_id` 和旧公开视图 epoch 被拒绝；
- [ ] 伪造 `caller_player_id`、`owner_player_id` 或 `gate_id` 的内部调用被拒绝；
- [ ] 农场主收到访客进入/离开的短暂提示。

## 4. 四种互动

- [ ] 访客投虫、捉虫、清理成功后各扣一次相应机会；
- [ ] 农场主自己捉虫、清理不扣机会；
- [ ] 同一块成长地不能同时存在两只虫；
- [ ] 虫源不能捉自己投下的虫；
- [ ] 两名访客并发操作同一地块时，先进入农场主 Actor Mailbox 的请求成功；
- [ ] 只有符合冻结规则的成熟作物可以偷取，配置热更新不改变已种作物参数；
- [ ] 被偷次数、保护产量和单次偷取量均按冻结配置校验；
- [ ] 访客背包容量不足时不会修改农场主地块，也不会产生邮件兜底；
- [ ] 偷取不满足条件时不增加 `stolen_quantity`，也不向访客发作物；
- [ ] 第二章偷菜、投虫任务只在对应访客 Saga 完成持久化后推进。

## 5. Saga 恢复

- [ ] 相同 `interaction_id` 重试不会重复扣机会、加作物或改地块；
- [ ] `VISITOR_RESERVED` 阶段中断后可释放预留；
- [ ] 访客 Checkpoint 已保存但 Saga 尚未标记 `VISITOR_RESERVED` 时可对账；
- [ ] `OWNER_APPLIED` 阶段中断后可从农场主回执继续访客提交；
- [ ] 农场主 Checkpoint 已保存但 Saga 尚未标记 `OWNER_APPLIED` 时可对账；
- [ ] `VISITOR_COMMITTED` 阶段中断后重试返回相同完成结果；
- [ ] Tcaplus CAS 冲突、重试性失败、旧副本和 Fence 拒绝均不会误判完成；
- [ ] Saga 同步 SaveCAS 不改变普通单玩家命令的异步 Dirty 语义；
- [ ] 未完成 Interaction 会被 Actor 激活或 Zone 定时任务对账；
- [ ] 终态 Interaction 保留 24 小时，未完成记录不自动删除。
