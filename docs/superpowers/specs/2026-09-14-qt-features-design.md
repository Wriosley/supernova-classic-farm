# Qt 功能对接设计

用户已确认一次补齐功能，并采用一个好友弹窗的方案。继续沿用当前 Qt Widgets 基础写法，允许直接的重复代码，保留默认控件外观。

- 主窗口：16 块地的文字列表；作物下拉框；购买/出售数量框；六种作物库存列表；种植、施肥、收获、清理、领奖和刷新按钮。
- 根据服务器 `shop`、`inventory`、`plots` 数组显示名称和数值。购买、种植、出售传选中的 `crop_id`。刷新后保留选中的作物与地块。
- 新增一个 `FriendDialog`，放好友列表、添加好友、查看农田、偷菜、邮件标题和正文。只有已加载好友农田中成熟的地块可偷取。
- 网络集中在原 `FarmApiClient`。好友请求使用普通 HTTP 方法和 Bearer 请求头，沿用一次一个请求的限制。收到偷菜快照先更新自己，再查询好友农田。
- 发给好友的邮件响应仅提示发送成功，不能放进本人的邮件缓存。系统邮件显示“系统”，好友邮件显示发送者用户名。
- 基本输入检查、HTTP/WS 错误提示、会话失效返回登录页；保留 20 秒心跳和简单的地块剩余秒数，不恢复自动重试、服务器时间校正或请求存储。
- 代码以实际后端响应为准；发现文档中的旧错误码时同步说明，不改变后端规则。
- 验证包括 Qt 构建、更新旧冒烟、多作物闭环、两个测试账号的好友/偷菜/邮件/重登检查，以及基本 GUI 检查。结果写入 docs/evidence。
- 保留已有暂存改动，不自动提交、推送、重建数据库或修改用户 .env。
